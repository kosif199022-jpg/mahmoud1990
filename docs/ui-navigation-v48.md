# KOSIF v48 — Navigation & Icon System

Presentation-only UI contract.

- Desktop (>=1180px): fixed RTL command rail with the primary audit destinations.
- Mobile: five equal destinations — الرئيسية، المراجعة، التحليلات، المجلس، المزيد.
- More sheet: semantic outline icon + title + short description for every action.
- Icon language: one outline stroke system, 20px primary / 17px compact / 28px large.
- Financial hierarchy: numeric values remain visually stronger than decorative icons.
- Dialogs and sheets: internal touch scrolling with safe-area-aware mobile navigation.
- Status colors remain semantic: success/risk/warning/info/AI; navigation uses the governed KOSIF accent.

This layer does not change accounting calculations, audit lifecycle state, evidence, AI output, approvals, security, or persistence.
