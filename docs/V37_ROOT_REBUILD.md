1. **Kosif Audit** — `/audit/`
2. **مفاتيح الثروة** — `/wealth/reader.html`

## مفاتيح الثروة

الدمج لا يختزل القارئ إلى «كتاب نصي». المسار `/wealth/*` يعمل كـ reverse proxy scoped إلى Worker مفاتيح الثروة الحالي عبر Service Binding `MAFATEEH`، مع fallback HTTPS. هذا يحافظ على التطبيق الكامل المستقل (القارئ، الصوت، التوقيت، البحث، الاستوديو، المؤثرات، Piper/أدوات القراءة، PWA وOffline) بدل نسخ نسخة ناقصة داخل Kosif.

الـService Worker الخاص بمفاتيح الثروة يُجبر على scope `/wealth/` حتى لا يسيطر على تطبيق Kosif كله.

## إصلاحات المراجعة المؤكدة

### الأهمية النسبية والقيود

خطأ v36 كان يقارن مبلغ القيد بكائن `computeMateriality()` كاملًا، فينتج `NaN` وتفشل عتبة الأهمية بصمت. `v37-audit-safety.js` يستخدم `performance` رقمًا، ويصلح سجل الأهمية القديم الذي كان يخزن الكائن ثم يعرض صفرًا.

### الميزان المعدل

`v36-outputs.js` أصبح يرفض:

- القيد غير المتوازن.
- الحساب غير المعروف.
- الاسم غير الفريد.
- إنشاء حساب صامت برصيد افتتاحي صفر.

المطابقة تبدأ برمز الحساب، ثم اسم فريد فقط. التصدير ممنوع إذا لم يتوازن الميزان المعدل.

### CSV

الخلايا التي تبدأ بـ `=`, `+`, `-`, `@`, tab, CR تُسبق بعلامة `'` لمنع Formula Injection.

### بيانات الشركات

`/api/kosif/companies` و`/api/kosif/company/private/*` أصبحت خلف جلسة المالك. كذلك النشر الصامت القديم من `ensureCurrentPublic()` يُحجب من جهة العميل والـEdge؛ إنشاء/نشر شركة يتطلب user activation و`x-kosif-intent:user-create`.

### SSRF / تحديث المصادر

`/api/kosif/sources/refresh` أصبح خلف جلسة المالك، و`custom=` غير الموثق محظور في v37. إضافة مصدر جديد تتم كـ allowlist change في الكود بعد المراجعة، لا كعنوان حر في URL.

### CORS

طبقة v37 تحذف wildcard CORS من API وتعيد CORS فقط عندما يكون Origin مطابقًا لأصل التطبيق.

### Service Worker

Root SW لم يعد يستخدم `ignoreSearch:true`، ويتجاوز عمدًا `/library/`, `/wealth/`, `/sales/`, `/api/`, وملفات الصوت المحمية. هذا يمنع بقاء محتوى محمي في كاش عام بعد سحب الإذن.

## Aghnam Sales Native Workspace

`/sales/` أصبح مساحة عمل أصلية خفيفة داخل Kosif، وليس iframe. حالياً تشمل:

- KPIs للمبيعات/الربح/الكمية/متوسط الطلب.
- الاتجاه الزمني، القنوات، الأصناف والفئات.
- جدول تكلفة وربحية حتمي.
- CRM للعملاء والبحث والإضافة.
- نسخ احتياطي JSON واستيراد JSON/CSV/TSV.
- مركز جودة بيانات بقواعد missing/duplicate/cost>revenue/phone.
- مركز إدارة تنفيذي يعتمد على الحسابات لا أرقام LLM.
- Diagnostics للحالة والتخزين والمصدر وحدود الثقة.

## Cloudflare

`wrangler.toml` نقطة دخوله الآن `src/suite-edge.js`. ما زالت bindings الحالية مستخدمة:

- `DATA` (KV)
- `ASSETS`
- `MAFATEEH` service binding

Workflow النشر يبني أولاً، ثم يشغل `npm run check` كاملاً، ثم `wrangler deploy` باستخدام السر الموجود أصلًا في GitHub Actions. لا تُطلب مفاتيح من المحادثة.

## ما لا يجوز كسره في أي مرحلة لاحقة

- لا custom fetch URL مفتوح.
- لا حسابات تسوية مجهولة أو غير متوازنة.
