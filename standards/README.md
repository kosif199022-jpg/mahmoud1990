# مكتبة المعايير داخل تمحيص

هذا المسار يضيف قارئ مكتبة المعايير إلى تطبيق «تمحيص» ويربط النصوص بطبقة Gemini كمراجع داعمة.

## حزمة البيانات

ضع الحزمة الأصلية التي تحتوي `data/library.json` و`data/b1` و`data/b2` و`data/b3` باسم:

`standards/library.zip`

عند وجودها على GitHub Pages سيحمّلها القارئ تلقائياً، يفك ملفات JSON داخل المتصفح، ويحفظها في IndexedDB للعمل دون إنترنت. إن لم تكن موجودة، يسمح القارئ باختيار نفس ZIP محلياً مرة واحدة.

## سياسة الاعتماد

- نصوص المكتبة مراجع داعمة للفهم والاستدلال والاستشهاد.
- الأولوية للحكم الرسمي الأحدث من IFRS/IASB وSOCPA والجهات النظامية الرسمية.
- عند تعارض نسخة قديمة مع إصدار أحدث: يُقدَّم الأحدث، مع ذكر ما كانت تقوله النسخة القديمة والفرق بينهما متى أمكن.
- ACCA/BPP مادة تدريبية مساندة وليست أعلى في القوة المرجعية من النص المعياري الرسمي.

## قدرات القارئ الحالية

- قراءة عربية/إنجليزية واتجاه تلقائي للنص.
- تكبير وتصغير الخط وتباعد السطور ووضع ليلي.
- بحث في الفصل أو الكتاب كله.
- حفظ التقدم ومكان القراءة على الجهاز.
- تظليل/ملاحظات وعلامات قراءة.
- قراءة صوتية من أصوات الجهاز مع التحكم في السرعة.
- متابعة الفقرة والكلمة أثناء الصوت حيث يدعم المتصفح أحداث حدود الكلمات، مع تمرير تلقائي.
- نسخ مرجع الفقرة.

## التكامل مع تمحيص

`bridge.js` يُحمَّل داخل تطبيق تمحيص الرئيسي ويضيف زر المكتبة، ويقرأ نفس IndexedDB كمصدر سياق محلي لطلبات Gemini. عند الاتصال المباشر بـ Gemini API يضيف أداة Google Search grounding للطلبات المدعومة، مع تعليمات صريحة بتقديم الإصدار الرسمي الأحدث عند التعارض.
