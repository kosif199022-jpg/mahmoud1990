# KOSIF v38 — Trusted Audit Intelligence OS

منصة مراجعة وامتثال محاسبي ذكية للسعودية، تجمع **محرك مراجعة حتمي** مع مكتبة المعايير والمصادر الرسمية و**مجلس مراجعين متعدد النماذج** — وترفعها v38 إلى نظام تشغيل ذكاء تدقيق موثوق.

> القاعدة الحاكمة في v38: الحسابات، حراس الترحيل، المطابقات، مدخلات المعاينة، عتبات الأهمية النسبية وثوابت المحاسبة — كلها حتمية بالوحدات الصغرى. الذكاء الاصطناعي يحلل ويطعن ويشرح ويستخرج ويصوغ، لكنه لا يرحّل قيدًا صامتًا ولا يحسب مبلغًا نهائيًا مساءلًا عليه ولا يصدر رأي المراجعة. الاعتماد بشري موثق دائمًا.

## ما الجديد في v38 (فوق قاعدة v36/v37 الكاملة)

### النواة الحتمية — `src/engine/v38-core.mjs`
- تطبيع الأرقام العربية/الفارسية وتحليل مبالغ دقيق بالوحدات الصغرى (BigInt) بلا فواصل عائمة.
- تحقق القيود وتوازنها، ترحيل غير قابل للتغيير بسلسلة بصمات SHA-256، وقيود عكسية موثقة المصدر.
- ميزان مراجعة وميزان معدّل، أهمية نسبية بمنهج ISA 320 حسب مخاطر الارتباط، تجميع تحريفات ISA 450.
- أعلام مخاطر قيود حتمية (مبالغ مقربة كبيرة، ترحيل راحات/خارج الفترة، حسابات وسيطة، مستخدمون مميزون…).
- معاينة حتمية قابلة للتكرار (عشوائي/منهجي/وحدات نقدية MUS) بنفس البذرة.
- ثوابت محاسبية: معادلة المحاسبة، تصفية الوسائط، وسلامة سلسلة البصمات (كشف أي عبث).
- جاهزية الإطارات حسب الفترة (IFRS 18/19، ISA 240 المعدّل…) كبيانات وصفية لا أحكام نافذة.
- حاسبات ZATCA (15%) والزكاة (2.5%) بالوحدات الصغرى.

### رسم الأدلة — `src/engine/v38-evidence-graph.mjs`
يربط الحسابات والقيود والمستندات والأدلة والمخاطر والإجراءات والنتائج والتسويات والضوابط ومراجع المعايير وآراء AI والقرارات البشرية وطلبات PBC في رسم واحد؛ الحواف تُصفّ حتى تسجيل طرفيها، ومقاييس التغطية (نتائج بلا أدلة / مخاطر بلا إجراء / آراء AI بلا حوكمة) حتمية.

### مجلس المراجعين v3 — `public/v38-council-v3.js`
خمسة مقاعد: OpenAI وClaude وGemini ومزود عام/محلي والمراجع البشري. جولة عمياء مستقلة، تجريد حقول السلطة (`calculated_materiality`, `final_opinion`, `approved_adjustment`, `posted_entry`) في الخادم، مصفوفة توافق/تعارض/فجوات أدلة حتمية، ثم قرار بشري موثق يُخزن في رسم الأدلة. توافق 4/4 لا يتحول أبدًا إلى اعتماد.

### مزود AI عام/محلي — `src/public-ai-provider.js`
بوابة متوافقة مع OpenAI أو محلية تضبطها متغيرات بيئة الخادم فقط (`KOSIF_PUBLIC_AI_*`)؛ المتصفح لا يمرر Base URL فلا تتحول الميزة إلى وكيل SSRF.

### المراجع الصوتي — `public/v38-live.js` + `src/v38-realtime.js`
محادثة صوتية WebRTC عبر OpenAI Realtime بسر مؤقت يفتحه الخادم (المفتاح لا يُخزَّن). استشارية فقط.

### نسيق ذكاء المصادر — `src/v38-source-intelligence.js`
سجل رسمي-أولًا بطبقات ثقة (IFRS/IAASB/SOCPA/ZATCA/NCA/SDAIA/NIST/W3C + مزودو AI وبحث)، كشف تغيّر مقنّن (HTTPS فقط، بلا بيانات اعتماد/IP/localhost، عينة 256KB، ≤20 هدفًا للطلب)، تاريخ إصدارات محدود (50)، وقدرة 5000 مصدر مخصص لطبقة D قراءةً وصفية فقط.

### واجهة v38 + التجربة التحريرية v39 — `public/kosif-editorial-v39.css`
هوية ورق دافئ/إسبريسو/برتقالي ذهبي مستلهمة من إيقاع Kitab Caffe ومكيّفة لهوية KOSIF، RTL أولًا، مع ثلاث صور أصلية مولدة خصيصًا للرئيسية والتقارير والمحادثة المباشرة. طبقة v39 تُحمّل أخيرًا وتلغي أولوية Canva Rose القديمة، وتستخدم كاش PWA جديدًا حتى لا تعود الألوان الوردية من ملفات مخبأة. وتبقى طبقات v38 الوظيفية كاملة: المركز، النواة، رسم الأدلة، المجلس، التقارير المحكومة، الاستيراد/التصدير، الحاسبات، المصادر، الكتب، المحادثة النصية والصوتية، والمختبر.

### التقارير الاحترافية — `public/v38-reports.js`
مسودة تقرير ارتباط جمالية: غلاف رسمي، ملخص تنفيذي بمؤشرات، منهجية الأهمية النسبية، مصفوفة نتائج بشدّات، أبرز الأرصدة، وخواتم اعتماد — طباعة/PDF بأنماط طباعة مخصصة، نسخة HTML مستقلة قابلة للإرسال، وبيانات JSON.

### الاستيراد والتصدير — `public/v38-io.js`
حزمة ارتباط JSON كاملة قابلة للنقل بين الأجهزة (بدون أي مفاتيح)، CSV بترميز آمن (UTF-8 BOM)، **Excel حقيقي XLSX** بكاتب ZIP مدمج (CRC32) للميزان والقيود، وفاحص قيود CSV يستخدم النواة الحتمية قبل قبول أي قيد.

### الحاسبات المحاسبية — `public/v38-accounting.js`
سبع حاسبات: النسب المالية (تصنيف آلي من الميزان)، الإهلاك (قسط ثابت/متناقص مضاعف/مجموع أرقام/وحدات)، ضريبة القيمة المضافة عبر الخادم، الزكاة، أعمار الديون بفئات ومخصصات تحفظ، التسوية البنكية بفروق غير مفسرة، ونقطة التعادل.

### مكتبة ملايين الكتب — `public/v38-books.js` + `src/v38-books.js`
بوابة بحث مهنية إلى **عشرات ملايين عناوين Open Library** عبر جسر خادم بتخزين 24 ساعة مقيّدًا بمواضيع المحاسبة والأعمال والتدقيق والتمويل، مع قراءة كاملة حيثما أتاحها أرشيف الإنترنت، وفهرس منسق محلي من 122 مرجعًا (كل معايير IFRS/IAS، معايير ISA، مراجع SOCPA/ZATCA الرسمية، والكلاسيكيات العالمية) كل بضغطة يبحث في الملايين.

### مختبر التدقيق الاصطناعي — `scripts/generate-v38-demo.mjs`
بذرة 380019: 1000 حساب، 6000 قيد متوازنة (13,972 سطرًا)، 25 مجموعة بيانات (عملاء، موردون، فواتير، بنك، أصول، مخزون، عقود، مخاطر، ضوابط، PBC، أدلة، مصادقات، أطراف ذات علاقة، نتائج وتحريفات مزروعة، تثبيتات ضريبة وتسوية)، و83 سيناريو معياريًا عبر IFRS/IAS/ISA/ISQM/COSO ومحلي سعودي — واجهته تشغّل تحققات حتمية (توازن BigInt، تجميع ISA 450).

## بنية التشغيل (الأساس القائم)
- `src/suite-edge.js`: موجه الجناح وواجهات `/api/kosif/v38/*` (الإصدار v38.0.0-root).
- `src/security-edge.js` → `src/worker.js`: طبقات الأمان والعمل الأصلي.
- `public/index.html`: واجهة الإنتاج (تُحقن فيها طبقة v38 عند `/audit/`).
- `public/legacy/core-v36.js`: المحرك الحتمي الأصلي المستعاد.
- ملفات v36/v37 القائمة تبقى كما هي كاملة (الميزان، PBC، Analytics، الحوكمة، المكتبة، القارئ…).

## الواجهات الجديدة
- `GET /api/kosif/v38/capabilities` — قدرة النظام (عام).
- `/api/kosif/v38/accounting/*` — parse-money, validate-journal, materiality, misstatements, sample, risk-flags, vat, zakat.
- `GET /api/kosif/v38/framework?start&end` — جاهزية الإطارات حسب الفترة.
- `/api/kosif/v38/evidence-graph` — عقد/حواف/نسب/تغطية (بجلسة مالك).
- `/api/kosif/v38/reviewer-notes` — ملاحظات مراجع منظمة (بجلسة مالك، بلا استبدال صامت للمعرفات).
- `POST /api/kosif/v38/council/matrix` — مصفوفة التوافق الحتمية وتجريد حقول السلطة.
- `POST /api/kosif/v38/realtime/session` — فتح جلسة OpenAI Realtime بسر مؤقت.
- `POST /api/kosif/v38/public-ai` — المزود العام/المحلي المضبوط بالبيئة.
- `/api/kosif/v38/sources/*` — السجل، الحالة، الفحص المقنّن، الضم الدفعي.
- `/api/kosif/v38/books/search|catalog` — بوابة الملايين والفهرس المنسق.

## الذكاء الاصطناعي (كما في الأساس + المزود الرابع)
- Gemini الافتراضي: `gemini-3.6-flash`، OpenAI: `gpt-5.6`، Claude عضوًا ورئيسًا عند تهيئة مفتاحه، وZ.ai متاح، والمزود العام/المحلي رابع مقاعد المجلس.
- محتوى المستندات دليل غير موثوق تعليميًا لمنع Prompt Injection.

## الأمان والحوكمة (كما في الأساس + v38)
- بيانات الشركات وعمليات v38 التشغيلية محمية بجلسة المالك؛ المصادر المخصصة للقراءة الوصفية فقط؛ التحديث الشبكي مقنّن.
- المفتاح الصوتي يمر للجلسة فقط ولا يُكتب في أي تخزين.

## سياسة المعايير
في السعودية، تعطي Kosif الأولوية للمعايير المعتمدة من **SOCPA**؛ المصادر الدولية للتحديث والتفسير، ولا يتحول مشروع أو إصدار مستقبلي إلى متطلب محلي نافذ قبل التحقق.

## التحقق
- `npm run check`: السلسلة الكاملة (syntax, payloads, regressions, contracts, accounting, v37, libraries-sales) + `npm run v38-suite` (نواة، رسم أدلة، تكامل API، عقد v38) — **390 تأكيدات، صفر إخفاقات**.
- `npm run v38-demo`: إعادة توليد حزمة المختبر الاصطناعي.
- سير نشر Cloudflare يتحقق حيًّا من `version === 'v38.0.0-root'` في `/__health`.
